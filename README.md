## About Me · 个人简介

Hi, I'm **Terre (海二旺)** — a **Shenzhen-based Senior Frontend & Full-Stack Engineer (8+ years)** and **AI Product Builder**.

- **Personal Website / 个人作品主页**：👉 **[https://aaoi.cc.cd](https://aaoi.cc.cd)**（在线履历、代表项目与工具入口）
- **Core Expertise / 核心方向**：
  - **DTC Independent Store & Frontend**：React / Vue / Next.js / Nuxt.js SSR、**Shopify Online Store 2.0 (Liquid / Sections / Schema)**、Headless (Storefront API / Hydrogen)、Core Web Vitals 性能优化、GTM / GA4 转化埋点与多语言 `i18n`。
  - **Full-Stack & Cross-Platform**：TypeScript、Node.js / Cloudflare Workers、微信小程序 / Taro / uni-app、复杂 B2B 交易结算与配置化组件库。
  - **AI Engineering & Automation**：多 Agent 工程工作流、内容/自媒体自动化流水线（[声稿工坊](https://studio.aaoi.cc.cd)）、Skills & MCP 工具治理。
- **Status / 当前状态**：现居深圳，开放 **独立站前端开发（Shopify / DTC） / 全栈与 AI 应用工程** 全职及合作机会。
